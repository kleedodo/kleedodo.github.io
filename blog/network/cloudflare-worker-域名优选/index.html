cloudflare worker 域名优选

约 190 字小于 1 分钟

dnscloudflare

2025-03-14

在域名的DNS记录里添加如下记录：

类型名称内容代理状态
CNAMEmyworkermyworker.cf.090227.xyz关闭

信息

小黄云，即cdn代理一定要关闭。

myworker.cf.090227.xyz 是cloudflare的优选域名，更多优选域名

在 workers路由 里点击添加路由。

选中你的worker，比如我这里的worker叫 myworker。

路由 填你域名，即 myworker.domain.com/*。

重要

路由 后面一定要加/*,示例： myworker.domain.com/*。
