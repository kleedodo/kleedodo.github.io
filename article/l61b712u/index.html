keymaps

配置文件: ~/.config/nvim/lua/config/keymaps.lua

使用jk来退出插入模式

vim.keymap.set("i", "jk", "<Esc>", { noremap = true })

rust-analyzer

配置文件: ~/.config/nvim/lua/plugins/rustaceanvim.lua

可以设置的选项

return {
  "mrcjkb/rustaceanvim",
  opts = {
    server = {
      default_settings = {
        ["rust-analyzer"] = {
          -- ... rust-analyzer相关的设置在这里设置
        },
      },
    },
  },
}

提示 procMacro async-trait is explitity disabled

在 rustaceanvim.lua 文件中写入如下内容，可开启 async-trait的宏展开

return {
  "mrcjkb/rustaceanvim",
  opts = {
    server = {
      default_settings = {
        ["rust-analyzer"] = {
          procMacro = {
            ignored = {
              ["async-trait"] = vim.NIL,
            },
          },
        },
      },
    },
  },
}

打开任意rust项目，使用:LspInfo查看配置是否生效。
